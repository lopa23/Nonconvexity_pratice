Saddle points and second-order stationarity

Here f(x, y) = ½x² + ¼y⁴ − ½y². Its gradient is (x, y³ − y) and its Hessian is diagonal with eigenvalues 1 and 3y² − 1. The origin is a strict saddle; (0, 1) and (0, −1) are the minima. Run different methods from the same start, and check the end point against the (ε, δ) conditions from slide 46. Move the cursor over the map to probe any point.

Slides 12–14, 35–39, 43–48 · Perturbed GD follows Jin et al. (2017): it adds a random kick of size up to αR only when ‖∇f‖ ≤ ε, and it stops, returning the point before the last kick, when f has not decreased by 10⁻⁴ within 40 steps of a kick.

Bayesian optimization versus grid search

The goal is to maximize a one-dimensional black-box function on [0, 1], as in the slide figures. A Gaussian process (RBF kernel, length-scale ℓ) models the function from the points evaluated so far. The next point maximizes the upper confidence bound μ(x) + κσ(x). The lower chart compares the error, true maximum minus best value found, with a grid search that uses the same number of evaluations.
